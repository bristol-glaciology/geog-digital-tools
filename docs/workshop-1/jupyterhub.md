# JupyterHub and "compute close to the data"

!!! note "This page is a stub"
    Content will be added after the workshop. For now, see the links below.

[JupyterHub](https://jupyterhub.readthedocs.io) is a multi-user server for Jupyter Notebooks. It lets a group of users (a class, a research team) each get their own Jupyter environment in a browser, without installing anything locally.

## What problem does it solve?

- Students don't need to install Python or configure environments
- Everyone works with the same software stack
- Large datasets can live on the server — no need to download
- Works on any device with a browser

## "Compute close to the data"

For large datasets (climate model output, satellite imagery, glacier inventories), moving the data to the user's laptop is impractical. JupyterHub lets users bring their code to the data instead.

## Hosted options

You don't need to run your own server to get started:

| Service | Notes |
|---------|-------|
