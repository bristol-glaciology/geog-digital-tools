# Dashboarding tools

!!! note "This page is a stub"
    Content will be added after the workshop. For now, see the links below.

Interactive dashboards let users explore data without needing to run code themselves. Several Python-native tools make this accessible to scientists without any JavaScript knowledge.

## The options

| Tool | Notes |
|------|-------|
| [Panel](https://panel.holoviz.org) | Most powerful; integrates with the whole HoloViz ecosystem |
| [Voilà](https://voila.readthedocs.io) | Turns a Jupyter Notebook into a dashboard with minimal changes |
| [Streamlit](https://streamlit.io) | Fast to prototype; good for standalone apps |
| [Dash](https://dash.plotly.com) | Plotly-based; more structured, more complex |

For scientists who already work in Jupyter, **Panel** or **Voilà** tend to be the lowest-friction entry points.
