# Static site generators

!!! note "This page is a stub"
    Content will be added after the workshop. For now, see the links below.

A **static site generator** (SSG) takes source files — Markdown, notebooks, reStructuredText — and compiles them into plain HTML/CSS/JS that can be served from anywhere, with no database or server-side code required.

## Why use one?

- **Free hosting** via GitHub Pages, GitLab Pages, Netlify, etc.
- **Version control** — your entire site lives in a Git repository
- **Focus on content** — write in Markdown or Jupyter Notebooks, not HTML
- **Fast and secure** — no server to maintain, no CMS to get hacked

## The landscape

| Tool | Language | Best for |
|------|----------|----------|
| [JupyterBook / MyST](jupyterbook.md) | Python | Notebooks, course notes, tutorials |
| [MkDocs + Material](mkdocs.md) | Python | Software documentation |
| [Jekyll](https://jekyllrb.com) | Ruby | Personal/blog sites (GitHub's default) |
| [Hugo](https://gohugo.io) | Go | Fast, general-purpose |
| [Sphinx](https://www.sphinx-doc.org) | Python | Python package documentation |
| [Quarto](https://quarto.org) | Python/R/Julia | Scientific publishing, reports |
