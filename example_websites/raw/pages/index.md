# A website about static websites

Hello! This is a very bare-bones example website to show you how you might take the same content - written in a mix of Markdown and Jupyter - and present it using a variety of static site generators.

Click through to the sub-pages here to show you what is going on:

 - [Example content page](.content.md)
 - [Example coding page](notebook.ipynb)

The coding page will only be present in formats where Jupyter Notebooks can be ingested. Otherwise, you can present raw code using Markdown code blocks.
