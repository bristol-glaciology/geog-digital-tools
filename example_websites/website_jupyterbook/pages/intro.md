# A website about static websites

Hello! This is a very bare-bones example website to show you how you might take the same content - written in a mix of Markdown and Jupyter - and present it using a variety of static site generators.

This book demonstrates how Jupyter Book can seamlessly integrate:

- Markdown pages for content
- Jupyter notebooks with executable code
- Mathematical equations
- Interactive visualizations

Browse the chapters to explore the different content types and how Jupyter Book handles them.
